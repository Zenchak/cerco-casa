# Cerco Casa

Mappa di lavoro per Bogdan e Camilla. Il sito Netlify mostra gli immobili candidati, filtri e un modulo `segnala-casa` per raccogliere link da analizzare.

## Aggiornare gli immobili

Gli immobili sono definiti in `homes.js`. Ogni modifica al branch `main` può essere pubblicata automaticamente da Netlify una volta collegato il repository al progetto.

Repository pubblico per consentire il deploy automatico Netlify dagli aggiornamenti del progetto.
